# Minecraft Autolooter

I saw a video of someone using Minescript to automatically loot chests, so I wanted to try and replicate it myself using Python.

The script detects the chest on the screen using image recognition and then automatically clicks through the chest slots while holding Shift to quickly transfer the items into the player's inventory.

## Technologies
* Python
* PyAutoGUI
* OpenCV
* Keyboard
* PyWin32

This was a small project made for fun to experiment with Python automation and screen recognition.
